# llm-gateway

一个**最小的大模型网关**：把多家厂商的私有协议统一成 OpenAI 兼容入口，并提供 token 级限流与多上游路由。

目标是**把大模型网关的几块核心机制写清楚**，而不是做一个功能完备的产品。

---

## 它做什么

把多家厂商的私有协议统一成 OpenAI 兼容入口 —— 但**这不是重点**。

AI 网关与通用 API 网关的区别，不在"能代理请求"，而在**围绕 token 的经济性**：
计量、预算、缓存折扣、成本路由。通用网关管的是**请求**，AI 网关管的是 **token 与钱**。

```
客户端 (OpenAI 格式)
        │
        ▼
┌─────────────────────┐
│  协议兼容表面 (IR)   │  OpenAI ↔ Anthropic 双向 + 保真度自检
├─────────────────────┤
│  计量 / 预算         │  虚拟 Key；预扣 vs 事后计量（可切换对比）
├─────────────────────┤
│  缓存 + 经济学       │  精确 + 语义；命中率盈亏平衡点
├─────────────────────┤
│  成本感知路由        │  按模型单价选址 + 成本上限保护
├─────────────────────┤
│  故障切换            │  重试边界 / 首 token 后断流 / 是否双计费
├─────────────────────┤
│  可观测              │  token 按 cache_status 分标签；成本汇总
└─────────────────────┘
        │
        ▼
   OpenAI / Anthropic / 兼容上游
```

> 架构细节见 [`docs/architecture.md`](docs/architecture.md)；
> **关键设计取舍见 [`docs/decisions.md`](docs/decisions.md)**（先读这个）。

## 范围

**Tier 1 · AI 网关的内核**（不做就不是 AI 网关）

1. **协议兼容表面 + 保真度自检** —— OpenAI ↔ Anthropic 双向转换，外加一组保真度探针
   （模型回显 / 假流式 / 虚报 usage / 上下文截断）—— **翻译保真度是这类网关的头号故障源**
2. **计量 / 预算 / 虚拟 Key** —— 区分 prompt / completion / **cached** token；
   ⭐ **同时实现「预扣」与「事后计量」两种模式并做可测量对比**（见 ADR-001）
3. **缓存 + 经济学** —— L1 精确 + 极简语义；⭐ **算出并展示命中率盈亏平衡点**
   （读缓存 0.1× 但写缓存 1.25–2×，**命中率不够时开缓存反而亏钱**）
4. **成本感知路由** —— 按模型单价选路，而不是只做加权随机

**Tier 2 · 生产必备**（缺了会在真实场景炸）

5. **故障切换** —— 重试边界、**首 token 之后断流**、**重试是否被计两次费**
6. **Prompt cache 透传** —— 请求体 canonical 化，避免改写请求体干掉上游缓存折扣
   （**"多数账单里最大的一笔没领的折扣"**）
7. **可观测 / 成本核算** —— 基础指标（token 数按 `cache_status` 分标签）+ 成本汇总

**Tier 3 · 前沿 / 可选**

8. 护栏（极简：一个规则级输入输出检查，为了看到这个功能）
9. MCP / Agent 网关（最小代理 + 工具级授权 —— "Agent 流量不是补全流量"）

**明确不做**（理由见 `docs/decisions.md`）

- ❌ 自适应路由（延迟 / 前缀亲和）—— 样本量不足时期望收益为负
- ❌ 内容安全的完整实现（AC 自动机 / 小模型 / 云 WAF 三路）· 完整 MCP 工具治理
- ❌ 多租户控制台 · 计费系统 · 多地域部署

## 快速开始

```bash
make build
./bin/gateway -config config.yaml
curl localhost:8080/healthz
```

需要 Go 1.21+。
